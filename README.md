# Linux Networking Practice

Практический проект по настройке, диагностике и исследованию компьютерных сетей в Linux на виртуальных машинах.

## Что отработано

- TCP/IP и модель OSI;
- IP-адресация и подсети;
- расчёт сетей с `ipcalc`;
- статическая маршрутизация;
- таблицы маршрутизации и `ip r`;
- диагностика соединений через `ping`;
- измерение пропускной способности через `iperf3`;
- настройка сетевого firewall с `iptables`;
- DHCP и динамическая конфигурация IP;
- NAT и forwarding;
- сетевые интерфейсы и Netplan;
- SSH tunnels;
- базовая диагностика сетевых проблем.

## Практический результат

Задания выполнялись на нескольких Ubuntu Server VM с настройкой сетевых интерфейсов, маршрутов, firewall-правил и проверкой соединения между машинами.

## Основные технологии

`Linux` · `Ubuntu Server` · `TCP/IP` · `ipcalc` · `ip` · `Netplan` · `iptables` · `DHCP` · `NAT` · `SSH` · `iperf3`

## Структура

- `src/` — отчёты и результаты практических заданий;
- `misc/` — вспомогательные материалы.

## Для портфолио

Проект демонстрирует базовые навыки Linux networking, network troubleshooting и понимания принципов TCP/IP, routing, firewall и NAT.
